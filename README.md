 AgroControl CBA:

AgroControl CBA es un sistema desarrollado/ aplicación monilitica desarrollada en Python para ayudar a llevar el control de la producción, el inventario y las ventas de un conexto cercano al agropecuario (parecido).

# ¿Qué hace este sistema/aplicacion sistema?

Este proyecto permite organizar de manera sencilla la información relacionada con productos, cultivos e inventario. También facilita el registro de ventas, alertas de stock, registros y ayuda a mantener un control actualizado del sistema en general.
Toda la informacion se guarda automaticamento dentro una carpeta llamada *data* y los archivos se guardan en formato *JSON*.

# Funciones principales (hasta el momento opcion 7)

Gestión de productos: Registro, actualización, búsqueda por código o nombre, desactivación de productos y manejo del catalogo de productos

Gestion de lotes productivos: Control del ciclo de producción desde el registro de la siembra hasta la cosecha o cancelación.

Movimientos de inventario: Registro de entradas, salidas por merma/retiro y actualización automática de stock al cosechar un lote.

Registrar venta: Registro de ventas directas en caja con validación de stock y generación de facturas detalladas en consola.

Consultar ventas: Consulta general y filtrado por fecha de las facturas registradas.

Alertas de stock: Monitoreo en tiempo real para identificar productos cuyo stock actual sea menor o igual al límite configurado.

Reportes: Análisis de ingresos totales, volumen de ventas, ranking Top 3 de productos más vendidos y valorización del inventario a precio de venta.

Persistencia de datos: Almacenamiento automático de la información en archivos JSON para que se conserven los datos del sistema al cerrar el programa.
