# AgroControl CBA

AgroControl CBA es un sistema desarrollado en Python para ayudar a llevar el control de la producción, el inventario y las ventas de una unidad agropecuaria.

## ¿Qué hace el sistema?

Este proyecto permite organizar de manera sencilla la información relacionada con productos, cultivos e inventario. También facilita el registro de ventas y ayuda a mantener un control actualizado de las existencias disponibles.

Toda la información se guarda automáticamente en archivos JSON, por lo que no es necesario utilizar una base de datos.

## Funciones principales (hasta el momento opcion 4)

Registrar y consultar productos.
Controlar la cantidad disponible de cada producto.
Crear y administrar lotes de cultivo.
Registrar cosechas y actualizar el inventario automáticamente.
Registrar entradas y salidas de productos.
Realizar ventas y generar facturas en consola.
Guardar toda la información de forma automática para usarla en cualquier momento.

## Objetivo del proyecto

Desarrollar una herramienta práctica que facilite el control de los procesos productivos, el inventario y las ventas dentro del Centro de Biotecnología Agropecuaria, contribuyendo a una mejor organización y gestión de la información.
